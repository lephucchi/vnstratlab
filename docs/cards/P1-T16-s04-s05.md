#### Rules and frozen params
- **S04_bank_pairs** `{form: 250, k: 5, entry_z: 2.0, max_hold: 10}` (Gatev, Goetzmann & Rouwenhorst 2006).
  - Formation window = last `form` sessions ending at asof. Pairs = the top `k` pairs by Pearson correlation of daily returns over the window (pairwise complete observations; require ≥ 80 % of the window observed for both, else pair skipped; tie-break by pair symbols).
  - Spread_t = cumulative log return of A − cumulative log return of B over the window (= log price ratio up to a constant), z-scored with the window mean/std (ddof 1). Use only days where both returns are observed; document.
  - Stateless position logic, derived from history at asof: a pair is "open" at asof if, within the last `max_hold` sessions (inclusive of asof), there was an entry session where |z| > entry_z, and since that entry z has not crossed 0 (sign change or exactly 0) and fewer than `max_hold` sessions have elapsed. Long the laggard of the entry session (z > 0 → B is the laggard; z < 0 → A). Compute z for past sessions using the formation window fixed at asof (state the choice; no lookahead since all inputs ≤ asof).
  - Weights: equal weight 1/k per open pair on its laggard; if two open pairs share the same laggard the weights add; total ≤ 1.
- **S05_residual_reversion** `{window: 60, entry_z: 1.5, n: 2}` (Avellaneda & Lee 2010).
  - Group return per session = equal-weight mean of available `ret_1d` across tickers that session.
  - For each ticker, OLS of its daily returns on the group return over the last `window` sessions (require ≥ 80 % observed); residuals; cumulative residual series; z-score of the last cumulative residual vs the cumulative-residual series mean/std (ddof 1).
  - Buy the `n` most negative z below −entry_z, equal weight 1/n, rest cash; tie-break by ticker.
- Both: strict param validation (exact keys, ints not bools, positive finite floats); only rows ≤ asof; deterministic.
