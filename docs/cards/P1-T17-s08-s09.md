#### Rules and frozen params

- **S08_momentum** — params `{L_months: 6, n: 4}`, `{L_months: 12, n: 4}`. Signal = `ret_6m_skip1m` (L_months 6) or `ret_12m_skip1m` (L_months 12); other L_months rejected. Buy the top `n` by signal, equal weight 1/n; NaN not eligible; fewer eligible → fewer names, rest cash; tie-break by ticker. (Jegadeesh & Titman 1993.)
- **S09_reversal** — params `{L_months: 6, n: 4}`. Same signal, buy the BOTTOM `n`. (Vietnamese reversal evidence; docstring notes S09 is the opposite ranking of S08 and the lab decides which survives.)
- Both use only rows dated exactly asof (lookback_sessions = 1, since the window lives in the feature); strict params.
