#### S00 rule (from docs/strategies.md, 4-block version)
- At asof, cross-section of tickers with features on asof (universe as visible in features; membership by date is P1-T05, issue #44).
- Blocks (each block = mean of the cross-sectional percentile ranks of its components, higher = better):
  - trend: `close_vs_ma20`, `close_vs_ma50`, `ret_60d`
  - relative strength: `rs_20d_vs_group_median` (or `rs_20d_rank`; pick one and document)
  - mean reversion: −`rsi_14` cross-sectional z-score → rank (lower RSI = higher score)
  - volume: `vol_vs_avg20`
- Score = weighted sum of block ranks. A ticker with NaN in a block component: that component is skipped within the block; if a whole block is NaN the ticker is not eligible (document).
- Trigger: breakout (`high_20d_break` true) OR oversold-in-uptrend (`rsi_14 < 35` and `close_vs_ma50 > 0`).
- Buy the top `top_n` by score that also have a trigger; equal weight 1/top_n each (fewer qualifiers → fewer names, remaining weight in cash; none → all cash, empty/zero weights). RSI threshold 35 is a code constant (frozen).
- Deterministic tie-break by ticker symbol.

#### S17 rule
- 1/N across tickers present in the features cross-section at asof (no NaN filter except tickers with no row on asof). Weights sum to 1.
