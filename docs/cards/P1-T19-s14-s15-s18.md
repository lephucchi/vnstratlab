#### Rules and frozen params

- **S14_low_volatility** — params `{window: 60, n: 4}`. Signal = `std_60d` on `asof`
  (`window` 60 only; other values rejected). Buy the `n` LOWEST, equal weight 1/n; NaN not
  eligible; fewer eligible → fewer names, rest cash; ties by ticker. Reads only asof rows
  (`lookback_sessions` 1). Basis: Frazzini & Pedersen (2014).
- **S15_sector_trend** — params `{lookback_months: 12}`, `{lookback_months: 6}`. Signal =
  `group_ret_12m` (12) or `group_ret_6m` (6) on `asof`; other values rejected. If the signal
  is > 0: 1/N across every ticker with a feature row on `asof` (same universe rule as S17). If it
  is ≤ 0 or NaN (or the rows disagree / are all NaN): empty target (all cash). Reads only asof
  rows. Basis: Moskowitz, Ooi & Pedersen (2012), time-series momentum.
- **S18_hrp** — params `{window: 250}`. History contract `lookback_sessions = window` (same
  pattern as S05). Steps, all deterministic:
  1. Return matrix = `ret_1d` for the last `window` sessions ≤ asof (pivot date × ticker, tickers
     sorted). Candidates = tickers with a row on `asof`.
  2. Eligible = candidates with ≥ 80 % non-NaN `ret_1d` in the window (`min_obs = ceil(0.8 ×
     window)`), and non-zero variance.
  3. Covariance / correlation pairwise with `min_periods = min_obs`. If any correlation is NaN,
     drop the ticker with the most NaN pairs (ties: drop the later ticker alphabetically) and
     repeat.
  4. Fewer than 2 eligible → if exactly 1, weight 1.0 on it; if 0, empty target.
  5. Distance `d = sqrt(0.5 × (1 − ρ))`; single-linkage clustering on the condensed `d`
     (`scipy.cluster.hierarchy.linkage(method="single")`); quasi-diagonal order from the leaves;
     recursive bisection with inverse-variance cluster variance (López de Prado 2016, ch. 16).
  6. Weights sum to 1 (fully invested), long-only.
  Basis: López de Prado (2016), Hierarchical Risk Parity.
- All three: strict params, long-only, weights finite and ≤ 1 in sum.

#### Acceptance criteria

1. S14: hand-computed weights on a 5-ticker cross-section; fewer eligible → cash; tie-break by
   ticker.
2. S15: signal > 0 → 1/N of the asof cross-section; ≤ 0 → empty; NaN → empty; 6 and 12 month
   variants read the right column (test).
3. S18: hand-checked HRP on a 3–4 asset fixture with a known answer (e.g. two highly correlated
   assets + one independent; verify against an independent numpy computation of the bisection);
   weights sum to 1; a ticker with too few observations is excluded; 0 and 1 eligible cases;
   result independent of input row/column order.
4. Long-only, sum ≤ 1, finite, for all three.
5. Only data ≤ asof: asof_guard + perturb-future-prices test (non-empty target asserted) for
   each strategy.
6. Deterministic, row-order independent.
7. Docstrings cite rule and basis.
8. Smoke backtest on the synthetic market long enough for the 250-session windows (≥ ~300
   sessions) with at least one invested target asserted per strategy.
9. `group_ret_6m` hand test + property-test coverage; `feature_version` changes to `features-v5`.
10. Packaged dry run reports 19 trials; packaged registry list pins the exact 12 ids.
11. `pytest && ruff check . && ruff format --check . && mypy` green with `FORCE_COLOR=1`;
    coverage ≥ 80 %.
