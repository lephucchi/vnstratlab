### P1-T15 — S01, S02, S03 (short horizon)

#### Rules and frozen params
- **S01_weekly_reversal** — feature `ret_5d_vs_group_median` (last week's return minus group median). Buy the `n` most negative, equal weight 1/n. Params: `{n: 2}`, `{n: 3}`. Tickers with NaN are not eligible; tie-break by ticker symbol. (Jegadeesh 1990.)
- **S02_breakout_volume** — close > highest CLOSE of the previous `lookback` sessions AND `vol_vs_avg20` > `vol_mult`. Equal weight across signals, max `max_n` (rank by `vol_vs_avg20` desc, tie-break by ticker); weight 1/max_n each, rest cash. Params: `{lookback: 20, vol_mult: 1.5, max_n: 3}` (the only set). The existing feature `high_20d_break` uses prior HIGHS, not closes, so add a new feature column `close_20d_break` (adjusted close > max adjusted close of the previous 20 good sessions; NaN during warm-up) to the feature store in `src/vnstratlab/features/` (bump FEATURES_CODE_VERSION to features-v2; add to FEATURE_COLUMNS; hand test + include in the no-lookahead property test coverage). S02 validates `lookback == 20` (the feature window) and rejects other values with a clear error. (Brock, Lakonishok & LeBaron 1992.)
- **S03_oversold_uptrend** — RSI(`rsi_len`) < `rsi_max` AND `close_vs_ma50` > 0 (ma_len must be 50). Buy up to `max_n` lowest RSI, equal weight 1/max_n, rest cash; tie-break by ticker. Params: `{rsi_len: 2, rsi_max: 10, ma_len: 50, max_n: 3}`, `{rsi_len: 14, rsi_max: 30, ma_len: 50, max_n: 3}`. rsi_len maps to features `rsi_2` / `rsi_14`; other values rejected. (Jegadeesh 1990; Moskowitz et al. 2012.)
- All: only rows dated exactly asof are used (as S00); validate params strictly; NaN trigger inputs count as "no".

4. Deterministic, row-order independent.
5. Docstring cites rule and basis.
