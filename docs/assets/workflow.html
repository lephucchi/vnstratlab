vnstratlab · development workflow

Reduced Git Flow. One task card = one feat/* branch; main and develop are protected (pull requests only). Tags are illustrative.

G1 · CI

Automated on every PR: ruff, strict mypy, pytest on 3 OS × 3 Pythons, coverage ≥ 80%, guardrails, gitleaks.

G2 · review

Independent review against the task card and checklist, not the author's summary.

G3 · readiness

Every release/*: investment benchmarks, cross-engine check, realism stress tests, product comparison.

G4 · owner

The owner reads the readiness report and approves. Only then is main merged and tagged.
